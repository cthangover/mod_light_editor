# Редактор освещения — статичные источники света сцены на ночном превью

Ночные сцены `time_base` освещаются строкой `light_set` сценария. Редактор освещения превращает эту строку в точки, которые вы двигаете по фону сцены: превью рисуется собственным ночным шейдером игры, так что вы видите, как сцена будет выглядеть после заката.

## Как открыть

Кнопка с молотком на игровом тулбаре → **Редактор освещения**.

## Расстановка света

![Редактор освещения со сценарием home_kitchen_cooking.scenario: два источника в списке, ночное превью кухни с лампой и кругом её радиуса, у выбранного источника X, Y, радиус 500, сила 1.0 и жёлтый цвет.](assets/light-editor.jpg)

1. Выберите сценарий, чью строку `light_set` вы правите (● отмечает сценарии, которые уже задают свет). Показывается фон его сцены; **Фон превью** выбирает другой.
2. Двойной щелчок по фону (или **+ Источник**) добавляет источник, перетаскивание двигает, Del удаляет выбранный. Не больше 10 статичных источников.
3. **Выбранный источник**: **X**/**Y** (доли экрана 0–1), **Радиус** (пиксели экрана игры шириной 1920 px), **Сила** (0–1) и **Цвет**.
4. Ctrl+S записывает строку `light_set` в сценарий; сценарию без неё она вставляется после заголовка. **Копировать строку** вместо этого кладёт команду в буфер обмена, чтобы вставить её вручную.

## Ограничения

- Только моды-папки; упакованные сценарии записать нельзя (строку можно скопировать).
- Свет привязан к сценарию: другой сценарий той же сцены может задавать другой.

## Зависимости

`tools_base`, `time_base`, `ui_base`, `scenario_tools_base` (читает сценарии; окно редактора сценариев не нужно).
Старый пакет `editor_tools` ставит этот мод вместе с остальными авторскими окнами.
